# Recorded measurements / 历史测量记录

These files preserve the inputs, package hashes, test outcomes and timings from the runs named in each record. Fields such as `local uncommitted build`, `sourceState` and `timestamp` describe that run, not the current checkout or Marketplace release. Failed attempts and older UI text are retained as evidence; changing release wording does not rewrite those observations.

这里保存各次运行的输入、安装包哈希、测试结果和计时。`local uncommitted build`、`sourceState`、`timestamp` 等字段描述当次实验，不表示当前工作区或 Marketplace 版本的状态。失败试次与旧版界面文字作为证据保留，不随发布措辞修改而改写。

Read the corresponding [comparison report](../comparison.md) / [中文对比报告](../comparison.zh-CN.md) for measurement scope. A current package must be built and audited again using the [release checks](../development.md); historical numbers alone do not certify it.
