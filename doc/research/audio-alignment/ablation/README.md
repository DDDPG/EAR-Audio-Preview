# 对齐 DSP 消融实验：2026-10-17

## 结论

在本轮固定语料上，相对 audioscope v1.1.8 的正例差距，可完整对应到声道策略和极性支持：各挽回26例，集合不重叠。普通178例双方均正确。部分白化与短窗口没有增加正例成功数；多候选的可观测准确率收益来自拒绝周期多解，尚未观察到正例上的纠错收益。

速度方面，短窗口是长输入最强的已测因素，声道选择也有明确收益。部分白化的净速度收益取决于它是否触发提前退出，不适合用一个平均数字概括。

这些结论仅针对本轮测试输入；不代表未见音频的总体准确率，也不证明部分白化在所有场景无用。实验没有修改生产算子。

## 关闭项的精确定义

- 声道选择关闭：改为Float32算术平均单声道，再沿用同样的能量／静音回退。该对照同时包含downmix分配和全长度累计的实际开销；不是仅比较声道评分循环。
- 部分白化关闭：直接使用`conj(A)*B`，移除幅度归一化和不再需要的幅度下限扫描；保留绝对相关峰、极性、阈值和精修算法。
- 多候选关闭：只精修最高粗峰，因此同时失去跨候选的歧义拒绝。这项消融衡量整个“多候选精修＋歧义检查”策略，不能独立归因到精修本身。
- 短窗口关闭：粗搜索使用所有可用音频，最多前60秒；仍降到约2kHz，仍采用相同FIR和16384样本精修。移除不再需要的短窗口锚点搜索。这不是把整套audioscope算法搬入。
- 极性附加对照：粗、细搜索都改为最大正相关，返回极性1，其他完整配置保留。

## 准确率结果

完整版本：230/230正例成功，88个负例均拒绝。

1. **关闭声道选择：204/230。** 少26例，均为声道相消的输入，全部被判作静音；没有新增负例误接受。
2. **关闭部分白化：230/230。** 负例仍全部拒绝。本语料未证明准确率收益。
3. **关闭多候选：230/230。** 正例不变，但22个周期多解案例由拒绝变为接受。它们是11个种子标签×2采样率，周期波形不依赖种子，实际只有2份不同采样率的波形，不能当作22份独立证据。
4. **关闭短窗口：230/230。** 负例仍全部拒绝。当前数据未显示截窗损失，但没有覆盖局部片段不具代表性的全部情形。
5. **关闭极性支持：204/230。** 少26例，均为整体反相：22个合成例和4个真实素材变体。
6. **audioscope：178/230正例正确。** 其52个失败集合恰好等于声道策略、极性支持两项消融的失败集合之并集。竞品接口没有拒绝状态，负例仅记录“返回估计”；不能把包装器的`accepted:true`当成竞品88次误接受。

16组合的每个因素都有8条开关配对：声道因素每条均增加26个正例成功，多候选因素每条均减少22个负例接受，白化／短窗因素每条通过数均不变。**在这组输入上没有观察到准确率交互**；这不等于统计证明没有交互。

## 主计时：以完整版本为参照

以下为12个“素材×轮次”中位耗时比的中位数，定义为`关闭项耗时 / 完整耗时`；比值大于1代表启用该项更快。完整版本约5.0–5.2ms（3秒）、10.5–10.7ms（30秒）。

1. **声道选择：3秒1.332，30秒1.447。** 启用后分别少约25%、31%的耗时。30秒各素材约从15.2–15.5ms降到10.5–10.7ms。主要差别是避免全长度平均混合；粗FFT与精修调用数量相同。
2. **部分白化：总体中位比3秒1.354、30秒0.914，但存在方向相反的素材，不能只看这两个总数。** 3秒A/C/D关闭后约慢35%，B反而快约8%；30秒A关闭后约慢12%，B/C/D反而快约9%。
3. **多候选：3秒1.005、30秒0.997。** 变化处于约±2%的范围，不构成稳定速度收益。这些精确副本在完整版本均早退，只进行了第一个候选的97次细化相关计算，所以该计时并不反映困难输入上完整三候选的成本。
4. **短窗口：3秒0.998，30秒3.472。** 3秒输入基本不变；30秒启用后耗时少约71%，约37ms降到10.6ms。三轮比值中位数分别3.476、3.465、3.482。

这些是“其他三个组件全部启用”条件下的单项差值，不是可相加的贡献比例。也不能把“3.47倍”乘到原先相对竞品的倍率上。长窗对照使用我们自己的较长FIR，因此30秒耗时甚至超过竞品；短窗收益可以大于相对竞品的总耗时差。

## 白化与多候选的速度交互

主计时后追加运行计数，再追加2×2计时对照。两者均标记为事后解释性分析，未改动主协议、源码或阈值。

- 完整版本的8个真实素材时长组合，都在第一个候选后早退：97次相关计算。
- 关闭白化后，3秒A/C/D、30秒A不再早退，升到291次；其余仍为97次。对应素材正好出现关闭白化后变慢。
- 保留短窗口时，30秒FFT长度为32768；关闭短窗口后为131072。双输入FIR乘加次数从约347万升至2316万。精修次数保持97次，解释了长窗主要增加的是滤波和FFT工作。
- 后续2×2计时保持声道／短窗启用，比较白化×多候选四组合，21次×2轮。固定成单候选后，关闭白化在全部8组素材时长上均更快：3秒约少6–13%，30秒约少8–10%。

因此，白化本身需要额外计算。当前部分素材的净提速来自它改变粗峰分布、触发提前退出，抵消并超过了归一化成本。**本轮支持的是速度上的条件性交互，尚未证明白化提高正例成功率。**

## 解释边界与后续决策

可以保留的事实判断：声道策略和极性支持解释了本语料相对竞品的正例优势；多候选策略提供歧义拒绝；短窗显著减少长输入开销；白化的准确率收益仍待更有区分度的数据验证。

不应据此直接删除白化或多候选。白化已有部分素材的早退收益，多候选的拒绝行为也有明确用途。下一步若继续简化，应先加入独立真实困难素材、重复结构、频响差异与局部干扰，检验收益是否能在非精确副本上复现。本轮不改生产默认配置。

## 复现与文件

需要Node.js24+、已准备好的本地A–D PCM，无需新增依赖。从`dsp-lab`运行：

```sh
npm test
node ablation/run.mjs accuracy > ablation/accuracy.log
node --expose-gc ablation/run.mjs bench > ablation/timing.log
node ablation/work-counts.mjs
node --expose-gc ablation/interaction.mjs > ablation/interaction.log
node ablation/run.mjs report > ablation/report.log
node ablation/run.mjs verify
```

`prepare`仅用于首次建立快照和manifest，已有manifest时会拒绝覆盖。复测会更新结果；原始结果如需保留，应先另存。执行需要原有本地PCM，原音频不进入Git。

- `protocol.json`、`manifest.json`：主实验定义和冻结哈希。
- `accuracy.json`：318×18完整逐例结果。
- `timing.json`：三轮正式计时原始样本及顺序块。
- `summary.json`：逐因素、逐家庭和16组合配对结果。
- `work-counts.json`：40个事后计数调用，输出均与未插桩版本一致。
- `interaction-protocol.json`、`interaction.json`：事后2×2速度交互。
- `verification.json`：结果、哈希、原始代码和PCM一致性门禁。

时间标签按上海时区记为2026-10-17；JSON内时间戳使用UTC，因此可能显示2026-10-16。
